# User Story 2.2: Say which part did not answer

## Story

**As a** duck operator whose Walk was refused
**I want** one sentence that names the servo or the IMU and what to do
**So that** I go to the right cable instead of wondering why the duck is not moving

## Background

Repo: **tnkr-studio** (`app/src`). Builds on 2.1, which delivers `lastErrorCode` and
`lastErrorJoint` to the store and the `IMU_NOT_FOUND` sentences.

The Drive page toasts a failed start at `app/src/pages/Drive.tsx:504-510`:
`plainCopy(strings.duckErrors[code] ?? strings.errors[code] ?? strings.errors.UNKNOWN)`.
Two problems for a pre-flight refusal:

- There is no `strings.duckErrors.MOTORS_SILENT`, so a silent servo on a duck renders the
  arm sentence: "A joint didn't answer. Check the arm has power, then try again."
- `plainCopy` substitutes `{joint}` from `CopyVars.jointLabel`
  (`app/src/lib/duckErrorCopy.ts`), but the toast passes no vars, so a `{joint}` sentence
  would render "This joint".

Agreed copy (architecture, 2026-09-09):

| code | Drive page (`strings.duckErrors`) | connect check (`strings.connect.duckErrors`) |
|---|---|---|
| `MOTORS_SILENT` | {joint} did not answer. Check the cable into that servo. | {joint} did not answer the check. Reseat its cable, then run the check again. |
| `IMU_NOT_FOUND` | The IMU sensor is not responding. Reseat its cable, then press Walk again. | The IMU sensor is not responding. Reseat its cable, then run the check again. |

The joint label comes from the manifest (`robot.joints[].label`, e.g. "Left hip yaw"), the
same lookup `Drive.tsx:434` already does for the calibration chip.

### Core Functions to Implement

```ts
// app/src/pages/Drive.tsx
function jointLabelFor(robot: RobotManifest | undefined, name: string | null): string | undefined {
  if (!name) return undefined
  return robot?.joints.find((j) => j.name === name)?.label ?? name
}

const start = async () => {
  setStartCheckOpen(false)
  await startWalk(picked)
  const { lastErrorCode: code, lastErrorJoint: joint } = useStudio.getState()
  if (code) {
    toast.error(
      plainCopy(strings.duckErrors[code] ?? strings.errors[code] ?? strings.errors.UNKNOWN, {
        jointLabel: jointLabelFor(robot, joint),
      }),
    )
  }
}
```

### Technical Considerations

#### Copy rules applied

- **Specific noun**: the joint label, not "a joint"; "the IMU sensor", not "the hardware".
- **Next move that changes something**: "Check the cable into that servo" and "Reseat its
  cable, then press Walk again". Pressing Walk again without reseating repeats the refusal,
  which is why the reseat comes first in the sentence.
- **Two vantage points**: the connect screen has a check to re-run; the Drive page has
  Walk. Same first clause, different last clause.

#### Error Scenarios to Handle

- `lastErrorJoint` names a joint not in the manifest (future agent, renamed joint): show
  the raw name rather than "This joint".
- Multiple silent joints: the agent names the first; the sentence names one servo. The
  count is in the console detail.

#### Performance & UX

- Toast appears with the refusal; no extra round trip.
